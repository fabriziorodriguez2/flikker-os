# Marca Flikker

## Archivos oficiales incluidos

- `flikker-wordmark.svg`: wordmark oscuro para fondos claros.
- `flikker-wordmark-white.svg`: wordmark blanco para fondos oscuros.
- `flikker-mark.svg`: isotipo oscuro.
- `flikker-mark-white.svg`: isotipo blanco.
- `flikker-logotype.svg`: logotipo oscuro.
- `flikker-logotype-white.svg`: logotipo blanco.

Los SVG son copias sin modificar de los originales del producto. No redibujar, deformar ni cambiar sus proporciones.

## Colores observados en el producto

| Uso | Color |
| --- | --- |
| Violeta principal | `#5C6BC0` |
| Violeta del panel actual | `#5C5BD6` |
| Violeta del símbolo de marca | `#9188F5` |
| Acento cálido | `#FFAB76` |
| Texto principal | `#1A202C` |
| Wordmark oscuro | `#3A3A3A` |
| Fondo neutro | `#F5F6FA` |
| Superficie | `#FFFFFF` |
| Borde neutro | `#E8EAF0` |

Para el PDF, usar `#5C6BC0` como acento principal y reservar los otros violetas para matices tomados de las capturas.

## Tipografías

- **Montserrat**: tipografía principal y customer-facing. Usarla en el PDF.
- **Syne**: usada en algunos títulos/display del panel. Es secundaria y no es necesaria para el documento.
